# Generated results

Research scripts and CLI commands write disposable runs here. Everything in this directory except this README is ignored by Git. Curated research evidence is stored once under [`research/`](../research/README.md).

Existing commands continue to work: they create `diagnostics/`, `m2b/`, `m2c/`, examples and shareable ZIPs here as needed. Generated runs do not automatically replace the curated evidence. Historical guides refer to these output paths because they describe running the original experiments.

For the already completed benchmark data, use the research index rather than rerunning the full suites. To inspect expanded evidence, follow its restoration instructions and use a directory outside this checkout. The repository does not keep expanded copies beside canonical archives.
